# Boost Converter

## Overview

This folder contains the Boost Converter design and simulation work carried out during my Power Electronics internship.

The converter was designed and simulated using LTspice to study the operation of a DC-DC boost converter and analyze its electrical waveforms.

## Work Performed

- Studied the operating principle of a Boost Converter
- Designed the converter circuit
- Implemented the circuit in LTspice
- Performed circuit simulation
- Observed and analyzed the output waveform
- Studied the effect of switching operation on converter performance

## Software Used

- LTspice

## Files

| File | Description |
|---|---|
| `boost.asc` | LTspice circuit schematic and simulation file |
| `output.png` | Simulation output waveform |

## Key Concepts

- Inductor charging and discharging
- Switching operation
- Duty cycle
- Output voltage regulation
- Energy storage and transfer
- Continuous and discontinuous conduction

## Learning Outcome

This work provided practical understanding of Boost Converter operation and the relationship between switching behavior, duty cycle, inductor current, and output voltage.
